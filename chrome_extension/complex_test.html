Сложные математические задачи

Задача 1. Квадратное уравнение

Решите уравнение: 2x² - 4x - 6 = 0

Задача 2. Текстовая задача на движение

Два пешехода вышли одновременно из одного пункта в одном направлении. Скорость первого пешехода 5 км/ч, а второго 7 км/ч. Какое расстояние будет между ними через 3 часа?

Задача 3. Площадь сложной фигуры

Найдите площадь прямоугольного треугольника, если его катеты равны 6 см и 8 см.

Задача 4. Арифметическая прогрессия

Среднее арифметическое чисел возрастает на 3 после каждого нового числа. На сколько 1000-е число больше первого?

Задача 5. Сложное выражение

Вычислите: (2 + 3) * (4 - 1) / 5 + sin(30°)

Задача 6. Система уравнений

Решите систему: { x + y = 10, 2x - y = 2 }

Задача 7. Проценты

Цена товара повысилась на 20%, затем понизилась на 20%. На сколько процентов изменилась цена по сравнению с первоначальной?
