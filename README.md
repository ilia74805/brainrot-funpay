## 🎯 **КАК ПОЛЬЗОВАТЬСЯ:**

### **Вариант 1: Автоматический режим**
1. Открой **любой тест** (Foxford, Yandex.Tutor и т.д.)
2. Кликни на **иконку расширения**
3. Нажми **"🚀 АВТО-ТЕСТ"**
4. Расширение **само найдет и решит все задачи**
5. **Отправит ответы на проверку**

### **Вариант 2: Многовкладочный режим**
1. Открой **несколько тестов** в разных вкладках
2. Кликни на **иконку расширения**
3. Нажми **"🌐 ВСЕ ВКЛАДКИ"**
4. Расширение **проходит по всем вкладкам**
5. **Решает каждый тест**
6. **Показывает статистику**

### **Вариант 3: Ручной ввод**
1. Кликни на **иконку расширения**
2. Перейди на вкладку **"Ручной ввод"**
3. Введи **свой вопрос**
4. Нажми **"Вычислить"**
5. Получи **ответ с пояснением**

## 📊 **ПРИМЕРЫ РЕШЕНИЯ:**

### **📐 Математика**
```
Вопрос: Решите уравнение: 2x + 3 = 7
Ответ: x = 2
Пояснение: 2x + 3 = 7 → 2x = 4 → x = 2
```

```
Вопрос: Площадь круга, r = 5
Ответ: 78.54
Пояснение: S = πr² = π × 5² = 78.54
```

```
Вопрос: Задача про Петю (среднее арифметическое)
Ответ: 5994
Пояснение: a₁₀₀₀ = a₁ + 3 × 2 × 999 = a₁ + 5994
```

### **🧪 Биология**
```
Вопрос: Что такое клетка?
Ответ: Клетка - это структурная и функциональная единица всех живых организмов.
Пояснение: Клетка состоит из цитоплазмы, ядра и клеточной мембраны.
```

```
Вопрос: Какие азотистые основания в ДНК?
Ответ: Аденин (A), Тимин (T), Цитозин (C), Гуанин (G)
Пояснение: A соединяется с T, C с G (принцип комплементарности)
```

```
Вопрос: Что такое фотосинтез?
Ответ: Фотосинтез - это процесс образования органических веществ из CO2 и H2O на свету.
Пояснение: Уравнение: 6CO2 + 6H2O + свет → C6H12O6 + 6O2
```

### **📊 Статистика**
```
Вопрос: Сколько способов выбрать 2 из 5?
Ответ: 10
Пояснение: C(5, 2) = 5! / (2! × 3!) = 10
```

```
Вопрос: Найдите среднее: 1, 2, 3, 4, 5
Ответ: 3
Пояснение: (1 + 2 + 3 + 4 + 5) / 5 = 3
```

```
Вопрос: Что такое вероятность?
Ответ: Вероятность - это мера возможности наступления события.
Пояснение: Вероятность вычисляется как отношение благоприятных исходов к общему числу исходов.
```

### **⚛️ Физика**
```
Вопрос: Найдите скорость, если s = 100м, t = 10с
Ответ: 10 м/с
Пояснение: v = s / t = 100 / 10 = 10 м/с
```

```
Вопрос: Найдите силу, если m = 5кг, a = 2м/с²
Ответ: 10 Н
Пояснение: F = m × a = 5 × 2 = 10 Н
```
