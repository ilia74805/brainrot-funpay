# 🚀 СУПЕР КАЛЬКУЛЯТОР - Полное решение задач в Chrome

**Многофункциональный калькулятор**, который **автоматически находит и решает математические задачи на ЛЮБЫХ сайтах!**

## 🎯 **ОСНОВНАЯ ФИЧА**

✅ **АВТОМАТИЧЕСКОЕ РЕШЕНИЕ ЗАДАЧ НА СТРАНИЦЕ**
- Расширение сканирует текст на сайте
- Находит математические выражения
- Подсвечивает их
- Показывает решения при наведении
- **Работает на ВСЕХ сайтах!** (включая тесты, форумы, соцсети)

## 📦 **Что умеет**

### 🔢 **Математика**
- ✅ Дробные выражения (`1/2 + 3/4`)
- ✅ Простые операции (`2+2`, `3*4`, `5-1`, `6/2`)
- ✅ Скобки и приоритеты (`(1+2)*3`)

- ✅ `sin(x)`, `cos(x)`, `tan(x)`, `cot(x)`

- ✅ Логарифмы: `log(x)`, `ln(x)`

### 📐 **Геометрия**
- ✅ Площадь: круг, квадрат, прямоугольник, треугольник, трапеция, ромб, параллелограмм
- ✅ Объем: куб, параллелепипед, шар, цилиндр, конус, пирамида

### ⚖️ **Единицы измерения**
- ✅ Длина: м, см, км, дюймы, футы, миля
- ✅ Масса: кг, г, фунты, унции
- ✅ Время: секунды, минуты, часы, дни
- ✅ Температура: °C, °F, K
- ✅ Объем: литры, мл, м³

### 🎲 **Комбинаторика**
- ✅ Факториал: `5! = 120`
- ✅ Перестановки: `A(5,3) = 60`
- ✅ Сочетания: `C(5,3) = 10`

### 📸 **OCR (по фото)**
- ✅ Распознавание текста с изображений
- ✅ Автоматическое вычисление

## 📥 **УСТАНОВКА**

### **Вариант 1: Chrome Extension (РЕКОМЕНДУЕТСЯ)**

1. Скачайте или клонируйте репозиторий
2. Откройте Chrome
3. Перейдите на `chrome://extensions/`
4. **Включите Режим разработчика** (в правом верхнем углу)
5. Нажмите **Загрузить распакованное расширение**
6. Выберите папку `chrome_extension/`

**ГОТОВО!** Теперь расширение работает на всех сайтах!

### **Вариант 2: GUI Приложение (PyQt5)**

```bash
pip install PyQt5 opencv-python pytesseract numpy Pillow
python app_gui.py
```

### **Вариант 3: Консольная версия**

```bash
pip install opencv-python pytesseract numpy Pillow
python main.py
```

### **Вариант 4: EXE файл (Windows)**

```bash
pip install pyinstaller
python build_exe.bat
```

EXE файл будет в `dist/SuperCalculator.exe`

## 🎮 **КАК ПОЛЬЗОВАТЬСЯ**

### **В Chrome Extension:**

1. **Авто-режим (по умолчанию):**
   - Расширение автоматически сканирует страницу
   - Математические выражения подсвечиваются
   - Наведите на выражение → появится решение
   - Нажмите на выделенное выражение → подробное решение

2. **Кнопка "Найти все задачи":**
   - Нажмите, чтобы пересканировать страницу
   - Показывает количество найденных выражений

3. **Ручной ввод:**
   - Перейдите на вкладку "Ручной ввод"
   - Введите выражение
   - Нажмите "Вычислить"

4. **Переключатель:**
   - Включите/выключите расширение
   - Когда выключено, сканирование не работает

### **Примеры использования:**

#### На сайте с тестом:
```html
<!-- На странице есть текст: -->
<p>Решите уравнение: x^2 - 4 = 0</p>
<p>Найдите площадь круга радиус 5</p>
<p>Вычислите: 1/2 + 3/4</p>

<!-- Расширение автоматически: -->
<!-- 1. Подсветит все выражения -->
<!-- 2. При наведении покажет решения -->
<!-- x^2 - 4 = 0 → x = 2, x = -2 -->
<!-- площадь круга радиус 5 → 78.54 -->
<!-- 1/2 + 3/4 → 1.25 -->
```

#### В поле ввода:
```html
<input type="text" value="2+2*2">
<!-- Расширение автоматически заменит на "6" -->
```
