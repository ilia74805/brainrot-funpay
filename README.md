# Калькулятор с OCR, дробями и геометрией

Этот проект предоставляет мощный калькулятор, который может:
- Вычислять математические выражения с дробями
- Извлекать и вычислять выражения из изображений (OCR)
- Вычислять площади и объемы геометрических фигур

## Установка

### Предварительные требования

Для работы OCR (pytesseract) требуется установленный Tesseract OCR:

**На Ubuntu/Debian:**
```bash
sudo apt update
sudo apt install tesseract-ocr
sudo apt install libtesseract-dev
```

**На macOS:**
```bash
brew install tesseract
```

**На Windows:**
Скачайте и установите Tesseract OCR с [официального сайта](https://github.com/UB-Mannheim/tesseract/wiki)

### Установка зависимостей

```bash
pip install -r requirements.txt
```

## Использование

### Запуск калькулятора

```bash
python main.py
```

### Режимы работы

1. **Ручной ввод выражений** - вычисление арифметических выражений с дробями
2. **OCR из изображения** - распознавание математического выражения из фото
3. **Геометрические вычисления** - вычисление площадей и объемов фигур

## Примеры

### Арифметические выражения с дробями

```
1/2 + 3/4 = 5/4 (≈ 1.2500)
5/6 - 1/3 = 1/2 (≈ 0.5000)
2 * (3 + 1/2) = 7
(1/2 + 3/4) * 2 = 5/2 (≈ 2.5000)
```

### Геометрические вычисления

#### Площади:
```
площадь круг радиус 5 → 78.5398
площадь квадрат сторона 4 → 16.0000
площадь прямоугольник стороны 3 и 4 → 12.0000
площадь треугольник основание 3 и высота 4 → 6.0000
площадь трапеция основания 3 и 5 высота 4 → 16.0000
площадь ромб диагонали 6 и 8 → 24.0000
площадь параллелограмм основание 5 высота 3 → 15.0000
```

#### Объемы:
```
объем куб ребро 3 → 27.0000
объем параллелепипед стороны 2, 3, 4 → 24.0000
объем шар радиус 5 → 523.5988
объем цилиндр радиус 3 высота 5 → 141.3717
объем конус радиус 3 высота 5 → 47.1239
объем пирамида площадь основания 20 высота 6 → 40.0000
```

#### С дробями:
```
площадь квадрат сторона 3/2 → 9/4 (≈ 2.2500)
площадь прямоугольник стороны 1/2 и 3/4 → 3/8 (≈ 0.3750)
объем куб ребро 1/2 → 1/8 (≈ 0.1250)
```

### OCR из изображения

1. Поместите изображение с математическим выражением в папку проекта
2. Выберите режим "Вычислить выражение по фото"
3. Введите путь к изображению
4. Калькулятор распознает текст и вычислит результат

## Поддерживаемые фигуры

### Плоские фигуры (площадь):
- Круг / Circle / Окружность
- Квадрат / Square
- Прямоугольник / Rectangle
- Треугольник / Triangle
- Трапеция / Trapezoid
- Ромб / Rhombus
- Параллелограмм / Parallelogram

### Объемные тела (объем):
- Куб / Cube
- Параллелепипед / Parallelepiped
- Шар / Sphere / Сфера
- Цилиндр / Cylinder
- Конус / Cone
- Пирамида / Pyramid

## Возможности

- ✅ Поддержка обыкновенных дробей
- ✅ Поддержка десятичных чисел
- ✅ Базовые арифметические операции (+, -, *, /)
- ✅ Скобки для группировки
- ✅ OCR для извлечения выражений из изображений
- ✅ Точные вычисления с использованием класса Fraction
- ✅ Вычисление площадей 2D фигур
- ✅ Вычисление объемов 3D тел
- ✅ Поддержка дробных значений в геометрии
- ✅ Русский и английский языки

## Ограничения

- OCR лучше всего работает с четкими, хорошо освещенными изображениями
- Поддерживаются только простые математические выражения
- Сложные формулы могут не распознаваться корректно
- Для OCR требуется установленный Tesseract OCR

## Технологии

- Python 3.x
- OpenCV (предобработка изображений)
- Tesseract OCR (распознавание текста)
- NumPy (работа с изображениями)
